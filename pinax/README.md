# Pinax

A project's **tablet**: the part it exposes to a second brain.

- a *pinax* (πίναξ): a tablet; Callimachus' *Pinakes* catalogued the
  library of Alexandria, one tablet per work
- each project keeps its own tablet; the vault is the library that
  catalogues them
- readable **without** Obsidian (GitHub, ADO, an editor), pluggable
  **into** Obsidian
- lives in a **native project**: built for a brain, agentic from birth
